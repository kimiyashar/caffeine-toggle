One switch. Two honest states.

Full mug, awake Mac. Empty mug, normal sleep.

No menu-bar maze. No timers to configure. The Control Center icon tells you exactly what your Mac will do before you close it.

OFF · DECAFFEINATED

Sleep works normally.

Closing the lid returns to standard macOS sleep behavior.

ON · CAFFEINATED

Your processes continue.

The display turns off when closed while the Mac and active work stay awake.

How it works

Native where you need it. Invisible when you don’t.

01

Add it to Control Center.

Install the app, open Edit Controls, search for Caffeine, and place the switch beside the controls you already use.

02

Fill the mug before a long task.

Toggle it on before starting an AI agent, build, download, render, or terminal command that needs to survive a closed lid.

03

Empty it when you’re done.

Toggle it off to release the power assertions and restore normal lid-close sleep behavior immediately.

!

Awake means awake.

Never put a caffeinated Mac in a bag, sleeve, bed, or poorly ventilated space. Closed-lid AI workloads can generate substantial heat and drain the battery quickly. Use a hard, open surface.

Questions, answered

Before you close the lid.

Can a Mac keep running with the lid closed?

Caffeine Toggle combines a macOS power assertion with a clamshell-sleep override. When the full mug is on, active local work can continue after the display closes. Because the clamshell interface is private and unsupported by Apple, test it on your own Mac before relying on it.

Will Hermes, Claude, or terminal jobs keep running?

The Mac stays awake, so local agents, terminal commands, builds, downloads, and active network work can continue. A remote website or service may still apply its own timeout independently.

Does the display stay on?

With the lid physically closed, the internal display turns off while the computer continues running. With the lid open and Caffeine Toggle on, the current build also prevents automatic display sleep.

How is this different from Amphetamine?

Caffeine Toggle is intentionally tiny: one open-source control that lives directly in macOS Control Center. Amphetamine is a mature, feature-rich menu-bar utility with timers, triggers, and extensive configuration.

Can I download a signed app?

Not yet. Version 1.7 is currently available as source code for developers to build with Xcode. A notarized public download is the next distribution milestone.
